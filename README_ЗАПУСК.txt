# УКРМЕТРОЛОГІЯ — Telegram-бот

Поточний етап: приймання заявок і договори лише для фізичних осіб. ФОП, юридичні особи та ОСББ додаються окремими етапами.

## Що виправлено

- Після введення телефону контактна клавіатура прибирається.
- Тип приладу автоматично визначається з послуги «Повірка/Встановлення водоміра» або «Повірка/Встановлення теплолічильника». Повторного вибору типу немає.
- Для ремонту та консультації тип не перепитується — менеджер уточнює його за потреби.
- Адреса перевіряється на наявність населеного пункту, назви вулиці та номера будинку.
- Марка, модель і серійний номер запитуються «за можливістю»; є кнопка «Немає».
- Після підтвердження менеджер отримує заявку та DOCX-проєкт договору з даними клієнта, номером і датою.
- Менеджер може замінити DOCX, затвердити або відхилити заявку.
- Для затвердження більше не потрібні IBAN і прайс — їх додамо пізніше.
- Доступ менеджера налаштовується через MANAGER_ID або список MANAGER_IDS.

## Встановлення

1. Python 3.11 або новіший.
2. У корені проєкту виконайте: python -m venv .venv
3. Windows: .venv\Scripts\activate
4. Встановіть залежності: pip install -r requirements.txt
5. Створіть .env на основі .env.example.
6. Переконайтеся, що шаблон лежить за шляхом templates/dogovir_fiz_osoba_template.docx.
7. Запустіть: python bot.py

## Маркери шаблону DOCX

Для автоматичного заповнення потрібні маркери в тих місцях шаблону, де мають стояти відповідні дані:

- {{CONTRACT_NO}} — номер договору 0001/ДД.ММ.РРРР
- {{DATE}} — дата договору
- {{CLIENT_NAME}} — ПІБ клієнта
- {{CLIENT_PHONE}} — телефон
- {{OBJECT_ADDRESS}} — адреса об’єкта
- {{SERVICE}} — послуга
- {{DEVICE_TYPE}} — тип приладу
- {{QUANTITY}} — кількість
- {{DEVICE_DETAILS}} — марка / модель / серійний номер
- {{COMPANY_NAME}} — ТОВ «УКРМЕТРОЛОГІЯ»
- {{COMPANY_ADDRESS}} — м. Одеса, Південна дорога, буд. 57
- {{COMPANY_PHONE}} — +380 67 009 13 88
- {{COMPANY_EMAIL}} — ukrmetrology2023@gmail.com

Обов’язкові маркери для номера, дати, ПІБ, телефону, адреси об’єкта та послуги перевіряються перед створенням файлу. Якщо їх немає, бот повідомить менеджеру про помилку замість надсилання незаповненого договору. Юридичні формулювання шаблону не переписуються.

## Налаштування .env

- BOT_TOKEN — токен Telegram-бота.
- MANAGER_ID=512322547 — основний Telegram ID менеджера.
- MANAGER_IDS=512322547 — додатковий список ID менеджерів через кому; можна вказати кілька.
- MANAGER_CHAT_ID=512322547 — куди надсилати заявки. Залиште ID менеджера для приватного чату.
- COMPANY_NAME=ТОВ «УКРМЕТРОЛОГІЯ»
- COMPANY_ADDRESS=м. Одеса, Південна дорога, буд. 57
- COMPANY_PHONE=+380 67 009 13 88
- COMPANY_EMAIL=ukrmetrology2023@gmail.com
- CONTRACT_TEMPLATE=templates/dogovir_fiz_osoba_template.docx

Щоб перевірити свій Telegram ID, надішліть боту команду /myid. Якщо кнопка затвердження показує «Недостатньо прав», додайте показаний ID до MANAGER_IDS у .env і перезапустіть бота. Натискати кнопку може лише дозволений ID.

## Важливо

- Нумерація договорів формується з послідовного ID заявки в SQLite та не скидається щодня. Не видаляйте data/bot.sqlite3, інакше історія та лічильник почнуться заново.
- Заявки зберігаються локально в SQLite. Google Sheets у цій версії не підключено.
- Перед публічним запуском потрібна політика конфіденційності.
- Не передавайте токен бота або ключі доступу в чат.
- Адресу компанії вказано за наданими даними; звірте написання з офіційними документами перед використанням у фінальному договорі.
