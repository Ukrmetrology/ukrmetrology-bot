УКРМЕТРОЛОГІЯ — Telegram-бот v5
================================

ВАЖНО: это новая сборка на основе согласованных требований. Старый локальный каталог v4 не изменялся.

1. Установите Python 3.11 или новее.
2. Распакуйте архив в отдельную папку.
3. Откройте терминал в этой папке и выполните:
   python -m venv .venv
   Windows: .venv\Scripts\activate
   pip install -r requirements.txt
4. Скопируйте .env.example в файл .env и вставьте токен Telegram-бота.
   MANAGER_ID уже установлен в 512322547; проверьте, что это Telegram ID менеджера.
5. Положите утверждённый шаблон договора для физлица в папку templates и назовите файл:
   dogovir_fiz_osoba_template.docx
6. ВАЖНО ДЛЯ АВТОЗАПОЛНЕНИЯ ДОГОВОРА:
   В шаблоне должны присутствовать текстовые маркеры (их нужно вставить в нужные места DOCX):
   {{CONTRACT_NO}} — номер договора формата 0001/ДД.ММ.ГГГГ
   {{DATE}} — дата
   {{CLIENT_NAME}} — ФИО клиента
   {{CLIENT_PHONE}} — телефон
   {{OBJECT_ADDRESS}} — адрес объекта обслуживания
   {{SERVICE}} — выбранная услуга
   {{DEVICE_TYPE}} — тип прибора
   {{QUANTITY}} — количество
   {{DEVICE_DETAILS}} — марка/модель/серийный номер
   Остальные юридические формулировки шаблона бот не переписывает.
7. Запуск:
   python bot.py

КАК РАБОТАЕТ:
- Клиент проходит короткую анкету с кнопками, подтверждает сводку.
- Клиенту показывается только «Заявку прийнято».
- Менеджеру сразу приходят все данные заявки и DOCX-черновик.
- Менеджер может загрузить замену DOCX, затвердить или отклонить заявку.
- При отклонении клиент автоматически получает уведомление.
- Тип прибора обязателен; варианта «Інший прилад» нет.
- В услугах используется «Ремонт приладу обліку».

ОГРАНИЧЕНИЯ И ПЕРЕД РЕАЛЬНЫМ ЗАПУСКОМ:
- Для отправки договора клиенту требуется заполнить COMPANY_IBAN и установить PRICE_LIST_READY=yes в .env.
  Пока банковские реквизиты и прайс не готовы, бот принимает заявки и отправляет менеджеру черновик,
  но не выдаёт клиенту договор с незаполненными финансовыми данными.
- Не включайте PRICE_LIST_READY=yes, пока цены действительно не внесены в договорный шаблон/процесс.
- Сейчас хранение заявок — локальная SQLite-база data/bot.sqlite3. Google Sheets API в этой сборке
  ещё не подключён; не считайте таблицу синхронизированной.
- Telegram и реальная доставка сообщений не тестировались без вашего BOT_TOKEN.
- Приватность/политика конфиденциальности должна быть подготовлена до публичного запуска.
- Не отправляйте токен бота и ключи доступа в чат. Храните их только локально в .env.
